الفرق بين Some و Any ومتى تستخدم كل واحدة

آخر تحديث: 2026-10-17

القاعدة الأساسية اللي يتعلمها أغلب الطلاب: some في الجمل المثبتة، وany في النفي والسؤال.

I have some apples. / عندي بعض التفاح. (جملة مثبتة)
I don't have any apples. / ما عندي أي تفاح. (جملة منفية)
Do you have any apples? / عندك أي تفاح؟ (سؤال)

الاستثناء المهم

نستخدم some في السؤال لما نكون نتوقع إجابة "نعم" أو نقدّم عرضًا/طلبًا مهذبًا:

Would you like some coffee? / تحب بعض القهوة؟ (عرض مهذب)
Can I have some water, please? / ممكن أخذ شوية ماء؟ (طلب مهذب)

لو استخدمت "any" بدل "some" بهذا السياق، الجملة تبقى صحيحة نحويًا بس تفقد طابع العرض المهذب وتصير سؤال محايد عادي.

any بمعنى "أي واحد"

فيه استخدام ثاني لـ any بالجمل المثبتة، بمعنى "أي واحد بدون تحديد":

You can choose any book you like. / تقدر تختار أي كتاب تحبه.

هذا الاستخدام مختلف تمامًا عن الاستخدام بالنفي؛ هنا any تعطي معنى "الحرية بالاختيار" مو "الغياب/الصفر".

مع الأسماء المعدودة وغير المعدودة

some وany تُستخدمان مع الأسماء المعدودة الجمع (apples) وغير المعدودة (water, money) بنفس الطريقة:

I need some money. / أحتاج بعض المال.
I don't need any money. / ما أحتاج أي مال.

تمرين قصير

  1. There isn't ___ milk in the fridge.
  2. I'd like ___ tea, please.
  3. Do you have ___ brothers or sisters?
  4. She bought ___ apples yesterday.
اعرض الإجابات
  1. any (جملة منفية)
  2. some (طلب مهذب)
  3. any (سؤال عادي)
  4. some (جملة مثبتة)
